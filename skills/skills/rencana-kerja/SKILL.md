# Rencana dulu, baru kerja

Sebelum mengerjakan, tulis untuk diri sendiri (maks. 8 baris):
1. **Tujuan akhir**: dokumen/angka apa yang harus jadi, untuk siapa.
2. **Masukan yang tersedia**: lampiran, file pengetahuan yang relevan (sebut namanya), data yang belum ada.
3. **Langkah** bernomor, termasuk pemeriksaan di akhir.
4. **Risiko salah**: angka, nama, tanggal, dasar hukum yang paling mungkin keliru.

Aturan:
- Baca hanya file yang ada di rencana. Tambah file baru ke rencana bila memang perlu.
- Bila data kunci tidak ada, jangan berhenti: lanjutkan dengan `[ISI: ...]` dan catat di "Pertanyaan untuk Rahula".
- Rencana tidak perlu ditampilkan panjang di jawaban akhir; cukup hasilnya.
